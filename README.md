## 📌 Project Overview

FabLens는 CMP 공정의 센서 데이터를 활용하여 **Material Removal Rate(MRR)를 예측하는 Virtual Metrology 모델**과 **SPC 기반 품질 모니터링**을 결합한 의사결정 지원 시스템입니다.

모델의 예측 결과와 SHAP 기반 원인 분석을 활용하여 공정 이상을 조기에 탐지하고, 실제 계측이 필요한 웨이퍼를 우선 추천함으로써 검사 효율과 품질 관리를 지원합니다.

### Key Features
- 📊 CMP 센서 데이터 기반 Virtual Metrology (MRR Prediction)
- 🧹 Data Preprocessing & Feature Engineering
- ⏱️ Time-aware Validation 기반 모델 평가
- 📈 SPC(Shewhart Control Chart)를 통한 공정 이상 탐지
- 🔍 SHAP 기반 예측 결과 해석 및 원인 분석
- 🎯 Rule-based Inspection Recommendation
- 📋 Streamlit Dashboard를 통한 결과 시각화
