# FabLens 기술 의사결정

이 문서는 현재 확정된 기술 기준을 기록합니다. 실제 데이터 확인으로 결정이 바뀌면 `05_DECISION_LOG_TEMPLATE.md` 형식으로 근거를 남긴 뒤 이 문서를 갱신합니다.

## TD-001. 프로젝트 단위

- **결정:** 분석 샘플은 wafer-stage입니다.
- **이유:** 타깃이 wafer identifier와 stage별 평균 제거율로 제공됩니다.
- **주의:** 원본 시계열 row를 독립 샘플로 모델링하지 않습니다.

## TD-002. 데이터 분할

- **결정:** 시간순 train/validation/test를 대표 평가로 사용합니다.
- **이유:** pad·dresser 누적 상태와 공정 순서 변화가 있을 수 있습니다.
- **규칙:** 동일 wafer-stage는 한 Split에만 속합니다.
- **보조 실험:** 랜덤 Split은 성능 과대평가 가능성을 보여주는 참고 자료입니다.

## TD-003. Feature Engineering

- **결정:** 통계 집계 Feature를 먼저 사용합니다.
- **초기 후보:** mean, std, min, max, delta, slope, duration, 누적 사용 관련 값.
- **목표 규모:** 30~60개.
- **제외:** 첫 MVP의 FFT 대량 Feature와 딥러닝 임베딩.

## TD-004. 모델

- **결정:** 선형 1개, RF 1개, GBDT 1개를 비교합니다. GBDT는 **XGBoost**입니다 (DL-20260720-001).
- **대표 선택:** 시간순 validation 성능과 안정성, 설명 가능성을 함께 봅니다.
- **금지:** test 결과에 반복 맞춘 모델 선택.

## TD-005. SPC 기준

- **결정:** Phase I 기준 구간의 실제 MRR로 중심선과 관리한계를 설정합니다.
- **Phase II:** 미래 구간의 예측 MRR을 모니터링합니다.
- **평가:** holdout 실제 MRR을 이용해 사후 탐지 성능을 계산합니다.
- **주의:** 관리한계는 실제 제품 규격이 아닙니다.

## TD-006. 평가용 이상 정의

- **결정:** holdout 실제 MRR이 Phase I 통계적 관리한계를 이탈한 경우를 프로젝트 내부 평가용 이상으로 사용합니다.
- **의미:** 통계적 공정 이상 후보입니다.
- **아님:** 실제 제품 불량, 수율 손실, 고객 품질 이슈.

## TD-007. SHAP

- **결정:** Tree 모델의 개별 예측 설명에 사용합니다.
- **표현:** 원인 후보, 확인 우선 변수, 예측 기여 Feature.
- **금지:** 물리적 원인 확정, 인과효과 주장.

## TD-008. 계측 우선순위

- **결정:** 최적화 모델보다 설명 가능한 규칙으로 시작합니다.
- **입력:** 예측 MRR의 SPC 상태, 데이터 품질 Flag, 선택적으로 모델 예측 편차.
- **출력:** 정상, 주의, 계측 권장, 데이터 확인, 높은 우선순위.
- **주의:** 실제 계측을 대체하지 않습니다.

## TD-009. Dashboard

- **결정:** Streamlit 단일 애플리케이션으로 구현합니다.
- **이유:** 4주 내 통합과 시연을 우선합니다.
- **제외:** FastAPI·DB 분리 배포.

## TD-010. 재현성

- **결정:** 환경 파일, Seed, Split Manifest, Feature Schema, 결과 CSV를 저장합니다.
- **필수:** 한 명이 만든 결과를 다른 팀원이 같은 명령으로 재생성할 수 있어야 합니다.

## TD-011. 조건 변수와 이상치 (2026-07-20 추가)

- **결정:** Stage A/B로 모델을 분리하지 않고, `STAGE`와 파생 변수 `chamber_group`
  (G123 / G456)을 조건 변수로 함께 사용합니다 (DL-20260720-002).
- **근거:** `CHAMBER`가 wafer-stage 안에서 1→2→3 또는 4→5→6으로 변하며, 이 계열이
  Stage A의 이봉분포를 완전히 설명합니다. 실제 구분선은 Stage가 아닙니다.
- **제외:** `MACHINE_ID`(상수), `AVG_REMOVAL_RATE > 1000` 4건 (DL-20260720-003).
- **주의:** `CHAMBER`의 물리적 의미는 확인되지 않았으므로 관측된 그룹 구분자로만 씁니다.
